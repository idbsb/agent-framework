# Windows 部署说明

## 环境

- Windows 10/11，64 位。
- Python 3.11–3.12；验证环境为 Python 3.12。
- Node.js 20+；验证环境为 Node.js 24。
- npm 10+。

## 数据文件

四个冻结正式文件位于 `outputs/`。组员 A 当前关系表位于 `组员图谱动态/重要岗位技能分析表.xlsx`。不要移动、覆盖或用 Excel 保存冻结文件。

后续正式文件建议放在 `outputs/knowledge_graph_v1.json` 和 `outputs/key_job_evolution_v1.json`，Adapter 会自动优先读取。

## 安装 Python 依赖

```powershell
cd <项目目录>
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

如 PowerShell 禁止激活脚本，可直接使用 `.venv\Scripts\python.exe`。

## 安装前端依赖

```powershell
cd frontend
npm install
cd ..
```

## 启动

后端：

```powershell
.venv\Scripts\python.exe -m uvicorn src.api.app:app --host 127.0.0.1 --port 8000
```

前端：

```powershell
cd frontend
npm run dev
```

访问 `http://127.0.0.1:5173`。也可双击根目录 `start_system.bat` 一键启动。

## 更新程序输出

```powershell
.venv\Scripts\python.exe -m src.emerging.export_emerging
.venv\Scripts\python.exe -m src.integration.export_frontend_data
cd frontend
npm run build
```

这些命令只读冻结数据，不会覆盖正式 Excel。

## 常见错误

- 页面提示“后端服务未启动”：确认端口 8000 的后端窗口仍在运行。
- `ModuleNotFoundError`：确认使用 `.venv\Scripts\python.exe` 并重新安装 requirements。
- `npm` 或 `vite` 不存在：安装 Node.js 20+，重开终端后执行 `npm install`。
- 端口占用：关闭此前启动的 8000/5173 服务后重试。
- 动态演化无数据：当前正式文件缺失，系统不会自行计算趋势。
- 图谱节点较少：当前只转换组员 A 已有三岗位正式关系 Excel；补入正式 JSON 后自动切换。
