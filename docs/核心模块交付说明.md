图谱组可读取JD Parser输出中的`jd_id`、标准岗位和`skills[].skill_id`建立岗位—技能关系；Evidence可作为关系证据，`need_human_review`用于过滤待审数据。

前端可通过FastAPI调用解析和匹配接口；列表页使用`GET /api/jobs`和`GET /api/skills`。匹配结果已包含维度分、缺失技能、学习建议和解释依据。
