# 核心算法闭环与统一数据接口设计

日期：2026-08-25  
范围：冲刺任务A（核心算法闭环 + 统一数据接口）

## 1. 目标与边界

本阶段一次性建立可运行、可解释、可评测的闭环：冻结正式数据读取 → JD 自动解析 → 简历自动解析 → 人岗匹配 → 技能差距 → 学习建议 → 基础评测 → 数据/API 接口。

不开展知识图谱、动态演化、新岗位发现、前端、PPT或视频。四份正式 Excel 只读，不覆盖、不重新编号；第三阶段报告只修复一致性统计显示。

## 2. 总体方案

采用“规则优先、证据约束、主动放弃、配置驱动”的实现：

1. 所有路径、字段、权重和版本由 YAML 管理。
2. `DataLoader` 是正式数据的唯一入口，解析器和匹配器不直接读取 Excel。
3. 技能抽取依次执行标准技能精确匹配、别名匹配、人工批准的组合词拆分；无原文证据不得进入正式结果。
4. 当前版本不依赖外部大模型，只保留受 Evidence 约束的候选补充扩展点。
5. 岗位预测优先使用正式映射，其次使用标题、职责和技能相似度；低置信度结果进入人工复核。
6. 匹配模型按必备技能、加分技能、项目、经验和学历五个维度解释性评分。

## 3. 组件与职责

### 3.1 配置

- `config/data_sources.yaml`：正式数据、人工技能依据和输出目录。
- `config/field_mapping.yaml`：中文字段到稳定内部字段的映射。
- `config/matching_weights.yaml`：五维匹配权重、阈值和分类边界。
- `config/version.yaml`：数据版本、Schema版本、更新时间和来源。

### 3.2 数据接口

`src/data_loader.py` 负责路径解析、工作表读取、字段映射、编号唯一性检查、技能ID检查和增量数据入口。路径相对项目根目录解析；后续更换文件只修改配置。

### 3.3 JD Parser

输入可以是正式数据行或稳定 JSON。输出包括 JD 编号、原始标题、预测标准岗位、置信度、职责、学历、经验、技能及人工复核标记。每个技能含正式 `skill_id`、标准名称、类型、置信度、证据、来源字段和接受状态。

### 3.4 Resume Parser

从学历、工作经验、工作经历、项目经历和技能清单中抽取结构化字段及有证据技能。输出与 JD Parser 使用同一技能 Schema。

### 3.5 Matching Engine

岗位要求由相同标准岗位的正式 JD 聚合产生：必备技能与加分技能分别统计；项目、经验和学历使用透明的规则评分。最终分数由配置权重加权，输出维度分、已具备技能、缺失技能、优势技能、优先补足技能、学习路径和解释依据。

### 3.6 评测

- 岗位预测准确率排除12条无正式真值记录。
- JD技能严格评测只使用三个重点岗位的人工技能分析作为有限 Gold Standard。
- 简历技能人工字段不是完整 Gold Standard，指标标注为“参考指标”。
- 匹配评测计算区间命中率、等级准确率和平均绝对误差，并强调人工区间是粗粒度专家标注。

### 3.7 API

FastAPI 提供：

- `POST /api/jd/parse`
- `POST /api/resume/parse`
- `POST /api/match`
- `GET /api/jobs`
- `GET /api/skills`

API 与内部函数共享 Pydantic Schema；图谱组和前端组既可调用 HTTP，也可直接导入 Python 服务对象。

## 4. 数据流

1. `DataLoader` 读取冻结 Excel 并验证版本、字段和编号。
2. Parser 使用技能词典与别名表建立只读索引。
3. JD/简历文本经过规范化、最长优先匹配和证据定位。
4. 匹配引擎基于解析结果及岗位聚合要求计算五维分数。
5. 评测模块根据适用的人工真值计算指标并标注边界。
6. 批处理结果输出为新 Excel，报告和交付文档记录指标、限制及接口用法。

## 5. 错误处理与人工复核

- 配置、文件、Sheet或必需字段缺失时明确报错，不静默降级。
- 出现未知 `skill_id`、编号重复或无证据技能时质量检查失败。
- 低岗位置信度、组合词歧义、无法定位证据或字段缺失时设置 `need_human_review=true`。
- 12条未确认岗位允许预测，但不进入岗位真值评测。

## 6. 增量更新与版本管理

新增 JD 通过数据接口读取并解析，不改变已有编号。新增技能必须基于上一版技能库追加新 `skill_id`，新增别名追加映射，不覆盖旧版；每次更新提高数据版本并保留旧文件。

## 7. 测试与验收

自动测试覆盖：路径配置、字段映射、技能边界、Evidence约束、ID唯一性、12条岗位排除、权重和Schema。批处理后检查三个结果 Excel、JSON Schema、真实指标计算及原始文件 SHA-256 未变化；每个 Excel Sheet 均进行值检查、公式错误扫描和视觉预览。

## 8. 交付物

新增 `src/`、`config/`、`docs/`、`reports/`、测试、三份结果 Excel 和核心模块交付说明；修改 `requirements.txt` 与第三阶段报告。完成后停止，不进入其他模块。
